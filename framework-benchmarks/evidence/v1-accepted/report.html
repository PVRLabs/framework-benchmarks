Protocol v1. Two sequential rounds per candidate. Latency runs from scheduled client slot to response completion, including dispatch, queueing and SSH transport. Guest memory reports sampled peaks and minima at roughly 1 Hz. PostgreSQL PSS sums proportional memory across sampled database processes. MemAvailable estimates guest headroom. The guest sampler shares the application vCPU. OS caches can remain warm.

Successful-request latency from failed or incomplete phases is listed in the table when independently verified. Charts include completed phases with verified environments.
