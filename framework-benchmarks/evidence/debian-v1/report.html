2026-11-23T23:22:39.636454+00:00 · completed · Linux benchmark host / Debian 13 guest

Protocol v1 with synthetic market prices. Two sequential rounds per candidate. Latency runs from scheduled client slot to response completion, including dispatch, queueing and SSH transport. Guest memory reports sampled peaks and minima at roughly 1 Hz. PostgreSQL PSS sums proportional memory across sampled database processes. MemAvailable estimates guest headroom. The guest sampler shares the application vCPU. OS caches can remain warm.

Successful-request latency from failed or incomplete phases is listed in the table when independently verified. Charts include completed phases with verified environments.
